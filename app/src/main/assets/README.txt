PLACE THESE FILES IN THIS FOLDER AFTER TRAINING:
=================================================
  agrishield_cotton.tflite    <- generated by train_model.py
  labels.txt                  <- generated by train_model.py
  model_metadata.json         <- generated by train_model.py

Training command:
  cd remix-Agrishield-main
  pip install tensorflow pillow matplotlib scikit-learn seaborn kaggle
  python train_model.py --download

Then copy:
  models/agrishield_cotton.tflite  ->  app/src/main/assets/agrishield_cotton.tflite
  models/labels.txt                ->  app/src/main/assets/labels.txt
  models/model_metadata.json       ->  app/src/main/assets/model_metadata.json

Then build:
  ./gradlew assembleDebug
